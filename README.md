# 📚 Project Name: Smart Class Schedule System

ระบบจัดการตารางเรียนอัจฉริยะ รองรับการสร้าง แก้ไข และแสดงผลตารางเรียน พร้อมฟีเจอร์ลากวาง (Drag & Drop) เพื่อความสะดวกในการใช้งาน

---

## 🚀 Features

- 📅 สร้างและจัดการตารางเรียน
- 🧑‍🏫 แสดงชื่อผู้สอน / ผู้สร้างตาราง
- 🏫 รองรับหลายห้องเรียน
- ⏰ จัดการช่วงเวลาเรียน (Time Slots)
- 🖱️ ลากวางรายวิชา (Drag & Drop)
- 🖨️ พิมพ์ตารางเรียน (Print)
- 🔐 ระบบล็อกอิน (Session-based)
- 💾 เชื่อมต่อฐานข้อมูล MySQL

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache / Docker
